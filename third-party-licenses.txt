Bundled fonts (self-hosted in assets/fonts/)
--------------------------------------------

Ten families ship inside the plugin and are served from your own site:
Roboto, Open Sans, Inter, Montserrat, Poppins, Oswald, Bebas Neue, Anton,
Playfair Display and Lora. The woff2 files are sourced from the @fontsource
project (https://fontsource.org).

  License: SIL Open Font License, Version 1.1 (OFL-1.1) for all ten. A copy of
  the OFL is provided in assets/fonts/OFL.txt. Copyright belongs to the
  respective font authors (see each family's project). The OFL is directly
  GPL-compatible.

The rest of the catalogue is not bundled. An administrator can download it
once to the site's own uploads folder, after which those families are served
locally as well, or opt into loading them from the Google Fonts CDN instead
(Settings, Fonts). Nothing is fetched from a font CDN unless that option is
switched on.


Provided by WordPress at runtime (NOT bundled)
----------------------------------------------

The @wordpress/* packages (element, i18n, hooks, api-fetch, components, …) are
provided by WordPress itself at runtime and are not shipped in this plugin.
WordPress and these packages are licensed under the GPL.

Build-only tooling (webpack/@wordpress/scripts, ESLint, Jest, Playwright,
node-canvas, @fontsource sources) is used only to build the plugin and is not
distributed with it.

GeoNames place index (assets/geo/cities.json)
---------------------------------------------
Derived from GeoNames, licensed under Creative Commons Attribution 4.0
(CC BY 4.0), https://creativecommons.org/licenses/by/4.0/
Source files: cities15000, alternateNamesV2 and countryInfo from
https://download.geonames.org/export/dump/

Derivation: cities of 15,000 inhabitants or more, reduced to their names in
the seven languages this editor ships in (en, de, fr, es, it, nl, pt),
coordinates rounded to four decimals, plus country code and population.
Rebuild with `node tools/build-gazetteer.mjs`. The source files are NOT
downloaded at run time; the index is built once and shipped.

Map geometry itself is not bundled: it is fetched at edit time through the
plugin's server-side geo proxy from OpenFreeMap and the OpenStreetMap
Overpass instances, and is (c) OpenStreetMap contributors under the Open
Database License (ODbL), https://www.openstreetmap.org/copyright
